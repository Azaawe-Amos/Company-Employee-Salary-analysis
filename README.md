# Company-Employee-Salary-analysis
An Excel-based data analytics project exploring employee salaries, job roles, experience levels, demographics and salary distribution through an interactive dashboard.

Project Overview

This project focuses on analysing employee salary data using Microsoft Excel. The goal is to understand salary distribution, employee demographics, job roles and the relationship between work experience and salary.

Tools Used
- Microsoft Excel
- Excel Formulas
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualisation

Project Objectives
- Analyse employee salary distribution.
- Compare salaries across different job titles.
- Examine average salaries based on years of experience.
- Identify the five highest-paid employees.
- Explore employee demographics by gender, department, education level and location.

Key Performance Indicators (KPIs)
- Total Salary: $1,153.82M
- Total Employees: 10,000
- Average Age: 35.46 years

Key Findings
- Managers have the highest total salary contribution among the job titles displayed.
- Executives have the highest average salary among the job categories displayed.
- Average salary generally increases across the experience groups shown.
- The dashboard identifies the five highest salary earners.

Dashboard Features

The interactive dashboard includes:
- Gender filter
- Department filter
- Education Level filter
- Location filter
- Salary by Job Title chart
- Top Five Highest Salary Earners chart
- Average Salary by Experience Years chart
- Average Salary by Job chart

Project Outcome

This project demonstrates the use of Microsoft Excel to organise, analyse and visualise employee salary information. It also shows how interactive dashboards can help users explore business data and make informed decisions.
